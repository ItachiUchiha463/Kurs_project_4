# Vigil — система моніторингу серверів (курсовий проєкт)

Повне ТЗ: `C:\Users\user\source\repos\1_курсак\ТЗ.md`. Записка — там же, у `src/`.

Стек: FastAPI (Python), React + TypeScript + shadcn/ui, PostgreSQL з TimescaleDB, агент для Linux і Windows, сповіщення лише в Telegram, розгортання на Azure for Students (Docker).

Межі MVP (знижена планка): реєстрація email + пароль, без робочих просторів і ролей, без англійської, без PDF-звітів (лише CSV), без перевірок з боку агента. Зберігання метрик — 30 днів.

Терміни: MVP до 26.10.2026, ядро v1.1/v1.2 до 01.11.2026, захист 10–12.11.2026.

ECC тут:
- агенти й рев’ю (`ecc:python-reviewer`, `ecc:typescript-reviewer`, `ecc:security-reviewer`) — коли користувач просить;
- тести — pytest для бекенду; важлива логіка (виявлення інцидентів, правила логічного виведення, авторизація) обов’язково з тестами, жорсткої вимоги 80 % покриття немає;
- хуки ECC — профіль minimal (налаштовано в `pluginConfigs`).
